# Modul 319

In diesem Repository befinden sich alle Dateien, die ich während des Modul 319 an der Gibb erarbeitet habe. Die Beispiele und Aufgaben sind in **C#** mit **.NET 9** umgesetzt.

## Über das Modul
Im Modul 319 geht es darum, eigene Applikationen zu entwerfen und zu implementieren.  
Die offizielle Modulbeschreibung findet man hier:  
[ICT Berufsbildung – Modul 319](https://www.modulbaukasten.ch/module/319/1/de-DE?title=Applikationen-entwerfen-und-implementieren)

Die Online-Dokumentation ist im **Smartlearn der Gibb** verfügbar.

## Inhalt
Das Repository enthält sämtliche Aufgaben aus dem Modul.  
**Tests sind möglicherweise nicht vollständig enthalten.**

## Technologien
- C#
- .NET 9
- JetBrains Rider (IDE)

## Hinweise
Das `.gitignore` ist auf **JetBrains Rider** ausgelegt.  
Bei Verwendung von anderen IDEs wie **VS Code** müssen eventuell weitere Einträge hinzugefügt werden.
## Zweck
Dieses Repository darf von anderen Lernenden frei genutzt werden – auch zum abschreiben :)
